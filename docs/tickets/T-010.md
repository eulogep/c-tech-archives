STEVEN_LEARNING_NOTES:
- PostgreSQL garde les métadonnées et le chemin relatif ; le contenu binaire reste dans un stockage privé.
- Un nom physique UUID évite les collisions, les chemins malveillants et la dépendance au nom envoyé par le navigateur.
- Un MIME type est une indication utile mais falsifiable ; il ne suffit pas à déclarer un fichier sûr.
- Une allowlist accepte explicitement les formats nécessaires plutôt que tenter de bloquer tous les formats dangereux.
- FileResponse sert un document seulement après contrôle de la vue Django.
- Le remplacement d’un fichier attend une politique de versioning, de conservation et de traçabilité.
